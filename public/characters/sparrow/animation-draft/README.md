# Sunny frame animation study

This is a review sample of a head turn, blink, attentive hold and return. Twelve newly generated drawings preserve Sunny's chestnut cap, cream cheeks, dark cheek spots and throat bib. The original turnaround remains unchanged and is not used as animation frames.

Open `sunny-animation-preview.html` in the project root for the standalone, offline preview. Its atlas is embedded; it supports pause, replay, single-frame selection, loop, speed selection and reduced-motion preferences. It makes no model or microphone requests.

`listen-atlas.webp` contains 4 columns and 3 rows of 384 px square cells. `manifest.json` records timing and registration. `sunny-listen.gif` is a shared-palette preview with a cream background. `listen-preview.webp` is a smaller atlas for the embedded preview. Source PNGs are retained in the authoring workspace.

Status: draft for review. Foot baselines are registered, but generated outlines and proportions can still drift slightly. This sample is not enabled in the voice runtime and has no mouth animation or speech synchronization. Review Sunny before producing Chirpy and Sage.
